# Rule: Automatic Knowledge Base Updates

## Trigger
- Execute this rule whenever code files are added, modified, or deleted.

## Actions
1. Identify which knowledge articles in the repository are impacted by the code changes.
2. Update the relevant `.md` files to match the new code logic, API endpoints, or architecture.
3. Keep the tone of the knowledge articles consistent with the existing documentation.
4. Ensure all internal markdown links remain functional after your edits.
